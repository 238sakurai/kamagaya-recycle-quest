# むだなしくん（鎌ケ谷市 ごみ減量・リサイクル推進キャラクター）使用に関するメモ

確認日: 2026-10-16

## 出典

- 市のキャラクター（企画財政課 企画政策室、更新日 2024-11-15）
  https://www.city.kamagaya.chiba.jp/sesakumidashi/shigaiyou_menu/character.html
- むだなしファミリー大集合！（クリーン推進課 計画管理係、更新日 2023-05-01）
  https://www.city.kamagaya.chiba.jp/kurashi-tetsuzuki/kankyo/kankyo-kouza/kamagaya_kkonline/112011301110a2.html

## 要点

- むだなしくんは「むだナシくんカンパニー」の一員で、所管はクリーン推進課。プロフィールは「1997年鎌ケ谷市のごみ減量とリサイクル推進のためにたちあがり『むだなしくん』となる。性格はあかるくて元気」「6才の男の子」。
- 仲間に、うれいなしちゃん・なしのつぶてくん・長寿ろうさん・ひまなしくん・かたなしくん・なしとげるくん・かなしくん・だいなしくん・ようなしくんがいる。
- 両ページとも **「キャラクター等のデザインの無断使用・転載はできません」** と明記。
- かまたんのような公開された使用要綱・申請書は見つからなかった。Web 公開する本ゲームで公式画像を使うには、所管課に相談して承諾を得る必要があると解釈する。
- 問い合わせ先
  - 市民生活部 クリーン推進課 計画管理係（電話 047-445-1222）: キャラクターの所管
  - 総務企画部 企画財政課 企画政策室（電話 047-445-1073）: 「市のキャラクター」ページの担当

## 本アプリの対応

- 公式画像は**使用していない**（`src/config/character.ts` の `imageSrc` は `null`、`officialImageApproved` は `false`）。
- 案内役はリサイクルマークをモチーフにしたオリジナルキャラクター「リサ丸」（`src/components/Mascot.tsx`）。むだなしくんに似せた造形は避けている。
- ゲーム内の「出典・このゲームについて」画面で、むだなしくんが市のごみ減量・リサイクル推進キャラクターであること、承諾を得るまで公式画像を使っていないことを説明し、市のキャラクターページへリンクしている。
- 承諾を得る際に確認すること
  - 画像の提供形式と、加工（縮小・トリミング・背景透過）の可否
  - 「むだなしくん」の名前をゲーム内のセリフや案内役の名前として使ってよいか
  - クレジット表記（「鎌ケ谷市ごみ減量・リサイクル推進キャラクター むだなしくん」など）の要否
  - 承諾の有効期間と、完成物の提出の要否
  - 非公式ゲームであることの明記方法

## 承諾を得たあとの手順

1. 提供された画像を加工せず `public/images/mudanashikun.<拡張子>` に置く。
2. `src/config/character.ts` の `imageSrc` にそのパス（`images/mudanashikun.<拡張子>`）を設定し、`officialImageApproved` を `true` にする。
3. 案内役の名前・説明文は `CHARACTER.official` の値に自動で切り替わる。必要ならクレジット文言（`credit`）を更新する。
4. `NOTICE.md` と README の「キャラクター」の記述を更新し、承諾の日付と条件を記録する。
5. `npm test` で設定の整合性テスト（画像パスと承認フラグの組み合わせ）が通ることを確認する。
